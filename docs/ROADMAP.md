# Дорожня карта

## Фаза 0 — Архітектура ✅ (поточний стан)

- Шари, контракти, чистий домен, 40 тестів
- Механіка №1 «пари» — робочий наскрізний зріз: запуск → раунд → підсумок
- Прогрес: XP, рівні, комбо, стрік, засвоєння колоди
- Дофаміновий шар: вібрація, WebAudio, банери, анімації плиток
- Три колоди-насінини: VS Code (20), SAP B1 (22), Jira (20)
- PWA-конфіг, збірка, лінива підвантажка колод

## Фаза 1 — Довести механіку пар до релізного вигляду

- Часточки (particle burst) у точці збігу; зараз лише банер і анімація плитки
- Плавний перехід «раунд → підсумок» без пробілу в 700 мс
- Порожні стани: колоду закрито, немає прострочених карток
- Іконки PWA (192/512), splash-екран
- Обробка помилок: пошкоджений JSON колоди, недоступний IndexedDB (приватний режим)

## Фаза 2 — Механіка №2: написання з клавіатури

- `domain/engine/typing.ts` за наявним контрактом `RoundEngine`
- Нормалізація введення: регістр, пробіли, розкладка, часткові збіги
- Підказка по буквах (перша літера → -60% XP)
- Вибір механіки: авто (нові слова — пари, вивчені — клавіатура) або вручну
- Мобільна клавіатура не має перекривати поле введення

## Фаза 3 — Утримання

- Теплокарта активності за 8 тижнів (дані вже пишуться, `activityByDay`)
- Денна ціль і її прогрес у шапці
- «Заморозка стріку» — один пропущений день на тиждень прощається
- Екран «слабкі місця»: картки з найбільшою кількістю помилок
- Локальні сповіщення-нагадування (за явної згоди, не на першому старті)

## Фаза 4 — Контент

- Імпорт колоди з CSV / JSON у застосунку
- Редактор карток
- Розширення колод: SAP B1 (Beas, нумерація, таблиці БД), Jira (JQL), VS Code (macOS-розкладка)
- Під-категорії всередині колоди за тегами (наприклад, лише «MRP»)

## Фаза 5 — Синхронізація (за потреби)

- Друга реалізація `ProgressRepository` поверх API
- Злиття за `updatedAt` (last-write-wins на рівні картки)
- Вхід — **опційний і ніколи не на старті**: застосунок має лишитися придатним без акаунта

## Свідомо поза планом

- Соціальні функції, рейтинги, друзі — інша продуктова задача
- Монетизація
- Десктопна версія: PWA і так відкривається на десктопі
