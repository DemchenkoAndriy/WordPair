# WordPair

Мікро-тренажер словникових пар: сталий список слів або обрана категорія
(VS Code, SAP Business One, Jira) у форматі 30–60-секундних раундів.

Задум — зайняти ті самі паузи, які зараз забирає скрол коротких відео,
і повернути з них знання. Звідси три головні вимоги: **запуск без кліків**,
**відчутний відгук на кожну дію**, **видимий прогрес**.

## Стан

Механіка №1 «утворення пар» працює наскрізно: відкриття застосунку одразу
починає раунд, збіги дають XP, комбо, звук і вібрацію, підсумок показує
точність і засвоєння колоди. Механіка «написання з клавіатури» — наступна фаза,
контракт рушія під неї вже готовий.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run test     # 40 тестів домену
npm run build    # tsc -b && vite build
```

## Структура

```
src/
├── domain/        правила навчання — чистий TypeScript, без React і без IO
│   └── engine/    механіки вправ за спільним контрактом
├── data/          IndexedDB, реєстр колод, валідація контенту
├── state/         zustand-стор: оркестрація
├── screens/       екрани
├── ui/effects/    звук, вібрація, нагороди
└── content/decks/ колоди у JSON
```

## Додати колоду

1. Створити `src/content/decks/<id>.json` за формою наявних.
2. Додати запис у `DECK_CATALOG` і в `loaders` у `src/data/decks.ts`.

Картки валідуються при завантаженні (`src/data/deckSchema.ts`) — помилка у JSON
дасть зрозуміле повідомлення, а не тихий збій.

## Додати механіку

1. Реалізувати `RoundEngine` у `src/domain/engine/`.
2. Додати рядок у `registry.ts`.

Нарахування XP, планувальник повторень, статистика й ефекти працюють із будь-якою
механікою без змін: усі рушії дають однаковий потік `Attempt`.
